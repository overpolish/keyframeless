# Thumbnails

These are the images shown in FCP as thumbnails.

Add the [toolset logo](../keyframeless.png) into FCP and apply the relevant effect, pick a keyframe which best displays the effect and grab the frame.

## Exporting

Once you are happy with the result, you'll have to export 2 separate files:

- `large.png` - `640 × 360`
- `small.png` - `192 × 108`

And then run through [TinyPNG](https://tinypng.com), more so for the sake of repository size than performance.

Simply copy across these two images to the `MotionTemplates` folder.
