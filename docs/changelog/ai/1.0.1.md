### New

- Added **Qwen3 14B** as a compact on-device model, and it's now the recommended local model for 24 GB Macs. It runs comfortably alongside Final Cut Pro without swapping, where the heavyweight models are better suited to 32 GB

### Improved

- The recommended local model now matches your Mac's memory, so a 24 GB machine no longer defaults to a model that's too large to run smoothly
- Requests that describe a look or a mood - "warm sunset gradient", "ocean tones", "moody purple" - now generate straight away instead of asking you to be more specific
- Leaner prompts are sent to on-device models, so local responses start faster
- Model downloads now show an animated "Finalizing" step while the files are verified, instead of appearing stuck at 99%

### Fixed

- On-device progress now shows the step it's actually on (planning, resolving colours, answering) instead of a generic "Thinking" that flickered and read as stuck
- Installing or updating Keyframeless AI now reliably starts the local helper, instead of occasionally leaving it unable to launch until the next login
