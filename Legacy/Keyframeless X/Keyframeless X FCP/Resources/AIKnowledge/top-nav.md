The top bar of the workflow extension contains, left to right:

- **AI button** (sparkles icon). Opens the AI popover for transforms and Q&A. The icon animates when at least one API key is configured. See `ai-transform`.
- **Tab selector** (currently only "Steno"; future tabs may be added).
- **What's New button** - opens the release notes for the current version.
- **Feedback button** - opens the hosted feedback form.
- **Setup / Edit toggle** - switches between the two main tabs. Edit is disabled until at least one clip has been transcribed.

A faint Keyframeless logo watermark sits behind the bar for branding.

**Update banner.** If a newer version of Steno is available, a banner appears above the top bar with a "What's New" link and a dismiss button. The dismissal persists for the current session.
