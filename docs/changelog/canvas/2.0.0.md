### New

- Rebuilt on the new Keyframeless timing engine - animate any property with keyposes across Basic and Advanced views, with no keyframes to manage
- Centerline tracing
- Movable toolbar
- AI integration
- Presets
- Interactive guides, including the animated arrow guide

### Improved

- Much faster drawing, selection, and mini-canvas preview for large, complex paths
- Proper 3D depth ordering when layers overlap

### Fixed

- Pinch-to-zoom now works even when the popover isn't focused
- Backspace no longer deletes the layer instead of a character while renaming
- Marker width now hides correctly when set to None
- Anchors are now preferred over curve handles when both sit under the cursor
