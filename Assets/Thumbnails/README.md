# Thumbnails

These are the images shown in FCP as thumbnails.

Try to convey the concept as simply as possible, keep the main shape as a rounded square where appropriate (use `example.psd` as a starting point).
- White fill,
- Rounded corners,
- Accent color as #fa6244.

Editing is can be done anywhere, my tool of choice is `Photopea`.

## Exporting

Once you are happy with the result, you'll have to export 2 separate files:
- `large.png` - `640 × 360`
- `small.png` - `192 × 108`

And then run through [TinyPNG](https://tinypng.com), more so for the sake of repository size than performance.

Simply copy across these two images to the `MotionTemplates` folder.
