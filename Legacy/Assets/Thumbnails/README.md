# Thumbnails

These are the images shown in FCP as thumbnails.

Add the [toolset logo](../keyframeless.png) into FCP (scaled to 50%) onto the [toolset background](./keyframeless-background.png) and apply the relevant effect, pick a keyframe which best displays the effect and grab the frame.

## Exporting

Once you are happy with the result, you'll have to export/[resize](https://www.adobe.com/express/feature/image/resize) to the following sizes:

- `large.png` - `640 × 360`
- `small.png` - `192 × 108`

And then run through [TinyPNG](https://tinypng.com), more so for the sake of repository size than performance.

Simply copy across these two images to the `MotionTemplates` folder.
