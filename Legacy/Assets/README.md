# Assets

Project assets go here - logos, and thumbnails.

## No Background Logo

Icon Composer does not have a way to export the icon without the background 🤦‍♂️ I took the main `png` icon (after making the background black temporarily), dumped it in Photopea, and masked out the background myself making sure to not leave any black pixels visible.

This icon is used in the Workflow Extension panel, so no background required.
