### New

- Expressions: ask Kai to make a property pulse, wobble, ease across the clip, or react to another value, and it writes the formula for you
- Kai can link properties between clips, so one clip can follow another clip's position, rotation, opacity, or any other parameter
- Ask Kai how an expression works or for help writing your own
- Added Qwen3 14B as the recommended local model for 24 GB Macs

### Improved

- Local model recommendations now match the memory in your Mac
- Prompts that describe a look or mood, such as "warm sunset gradient" or "moody purple", now generate straight away
- Local models receive smaller prompts, so answers start faster
- Model downloads now show Finalizing while the downloaded files are checked

### Fixed

- Progress now shows what Kai is doing instead of flickering between generic Thinking messages
- Installing or updating Kai now starts the local helper straight away
