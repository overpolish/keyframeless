### New

- rebranded AI Captions to **Steno**
- native caption generation - SRT, iTT, and CEA-608
- srt import workflow
- caption transformation between caption types
- full support for bundled audio filters (compressor, etc)
- diff preview for AI edits
- waveform rendering loader
- point, rotation, and dropdown support for value customization

### Improved

- click and drag selection behaviour
- deselect UI, deselects all by default
- gap at the start of captions for easier syncing
- y position default changed from 20% to 50% to account for non centered templates

### Fixed

- disabled compound clip audio still being detected
- disabled audio still recognized
- overlay not showing on process/reprocess click
- transcription list crash
- custom templates not rendering text
- custom templates not replacing placeholder text
