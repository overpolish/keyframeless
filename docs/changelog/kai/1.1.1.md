### New

- Kai now finds MLX models you already downloaded outside Keyframeless, with mlx_lm, huggingface-cli, or LM Studio, and lists them under Your models so you can pick one without downloading the same files twice

### Improved

- Shader code Kai writes is now compiled before you see it, and Kai fixes its own compile errors, so the code that lands in the editor works
- Asking for a control that doesn't exist yet, like "add a Shatter slider" or "an edge glow colour", now writes the shader for it instead of trying to animate a control that isn't there
