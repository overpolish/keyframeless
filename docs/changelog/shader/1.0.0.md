### New

- Shader launches: write GLSL shaders (Shadertoy-style) and run them live as an effect in Final Cut Pro and Motion with a built-in code editor
- Your clip is available to the shader as its source texture, so shaders can react to and composite over the footage underneath
- Multi-pass shaders with buffer tabs, so feedback and multi-stage effects work the way they do on Shadertoy
- Directives turn a uniform into a real control: mark one up as a color, slider, angle, point, choice, and it appears in the inspector
- Built on the Keyframeless timing engine - animate any uniform with keyposes across Basic and Advanced views
- Dynamic on-screen controls for shaders that need it
- GL Transitions support
- AI integration and interactive guides
