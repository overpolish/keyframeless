id: languages
summary: Supported transcription languages (Whisper supports 65+; Parakeet is more limited)
---

Whisper-based models support 65+ languages, plus an auto-detect option. Selected via a searchable language picker in the Setup tab.

Full Whisper language list: Afrikaans, Amharic, Arabic, Assamese, Azerbaijani, Bashkir, Belarusian, Bulgarian, Bengali, Tibetan, Breton, Bosnian, Catalan, Czech, Welsh, Danish, German, Greek, English, Spanish, Estonian, Basque, Persian, Finnish, Faroese, French, Galician, Gujarati, Hausa, Hawaiian, Hebrew, Hindi, Croatian, Haitian, Hungarian, Armenian, Indonesian, Icelandic, Italian, Japanese, Javanese, Georgian, Kazakh, Khmer, Kannada, Korean, Latin, Luxembourgish, Lingala, Lao, Lithuanian, Latvian, Malagasy, Maori, Macedonian, Malayalam, Mongolian, Marathi, Malay, Maltese, Myanmar, Nepali, Dutch, Nynorsk, Norwegian, Occitan, Punjabi, Polish, Pashto, Portuguese, Romanian, Russian, Sanskrit, Sindhi, Sinhala, Slovak, Slovenian, Shona, Somali, Albanian, Serbian, Sundanese, Swedish, Swahili, Tamil, Telugu, Tajik, Thai, Turkmen, Tagalog, Turkish, Tatar, Ukrainian, Urdu, Uzbek, Vietnamese, Yiddish, Yoruba, Cantonese, Chinese.

**Translate to English toggle** - appears in the Whisper picker; transcribes the source audio AND translates the output to English. Disabled if English is already the selected language. Not available with Parakeet.

**Parakeet language support:**

- Parakeet 0.6B v2: English only.
- Parakeet 0.6B v3: 25 European languages.

**Profanity filter** badges appear next to languages that have profanity word lists available; the Censor toggle in the Edit tab uses these lists.
