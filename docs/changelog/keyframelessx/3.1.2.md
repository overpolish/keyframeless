### New

### Improved

- The published sources list in Sonar now mentions that deleting is safe - plugins remember which clips a source used, so a deleted source can always be republished later

### Fixed

- Projects using compound clips nested inside other compound clips now import correctly - their audio previously showed up as a stack of full-length clips all starting at zero instead of the real trimmed segments in their timeline positions
- Screen recordings that carry the mic on a separate audio track now show waveforms, transcribe and play back properly - only the first track (usually near-silent system audio) was being read, so the voice was dropped
- Clip audio now mixes the way Final Cut Pro does: channel sources are summed with their volume adjustments applied, where before everything was averaged together and could come out much quieter than in your project
- Renaming a project no longer breaks Sonar's automatic clip reselection - a shader waiting on a deleted source now finds its clips even when the project name only matches with different capitalization
- Publishing or renaming a Sonar source whose name only differed from an existing one by capitalization (like DEMO next to Demo) no longer overwrites the older source and leaves a blank row in the list - it now gets a number suffix like any other taken name
