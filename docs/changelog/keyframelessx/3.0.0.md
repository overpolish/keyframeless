### New

- Renamed AI Captions to **Steno**
- Native caption generation in SRT, iTT, and CEA-608
- FCP 12.3 subtitle support
- SRT import workflow
- Convert captions between formats
- Full support for bundled audio filters, including the compressor
- Diff preview for AI edits
- Waveform rendering loader
- Point, rotation, percentage, and dropdown fields for value customization

### Improved

- Smoother click-and-drag selection
- Deselecting now clears all captions by default
- Added a gap at the start of captions for easier syncing
- Default Y position moved from 20% to 50% to suit non-centered templates
- Replaced the slider with a freeform value field
- Customize values side bar consistency
- Switch `Captions` role to `Subtitles` matching FCP's direction

### Fixed

- Disabled compound clip audio is no longer detected
- Disabled audio is no longer recognized
- Overlay now appears on Process and Reprocess
- Fixed a crash in the transcription list
- Custom templates now render text correctly
- Custom templates now replace placeholder text
- Custom templates now work with text filters (outline and drop shadow)
