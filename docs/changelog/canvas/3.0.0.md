### New

- Expressions: drive any property from a formula instead of a value or keyframes. Right-click a property label and choose Add Expression
- Live preview: play or scrub the timeline with a keypose or Constants editor open and its preview follows the playhead, then snaps back to the frame you're editing

### Improved

- The timeline ruler is always available now, even before anything is animated, so you can scrub the playhead straight from the inspector (and preview it in an open editor) without leaving it
- The keypose or interval you're editing now highlights in the timeline, and the Constants button lights up while its panel is open, so it's always clear what the editor is controlling
- The keypose, Constants, and interval editors now open in one consistent spot beside the inspector instead of jumping around as you move between them, and each has a close button
- Press Escape to close an open editor (keypose, Constants, or interval) instead of reaching for its close button, and a search box inside an editor now releases focus on Escape, Return, or a click away, so the Spacebar keeps controlling playback

### Fixed

- Fixed Final Cut crashing when Canvas was applied by double-clicking it in the Effects browser
- Fixed an on-screen control in an editor's preview sometimes sticking to the cursor when a keypose editor was open over the Constants panel: the drag could stop responding partway through, and the undo that followed could crash Final Cut
- Fixed the inspector using a whole CPU core while simply sitting open, which made the interface sluggish
- Fixed the layers panel occasionally not appearing beside an editor the first time one was opened after launching Final Cut, where it took closing and reopening the editor to bring it back
- Fixed a crash that could occur when opening a keypose editor from the Constants panel
- The inspector's option menus (on-screen controls, parameter order, and so on) now close when you click anywhere off them
- Fixed hidden on-screen controls not reappearing when holding Option in Motion
- Fixed the inspector preview occasionally rendering blurry with an oversized on-screen control
- Fixed a crash when pressing Escape while renaming a layer in the layers list
- Fixed renaming a layer: typing now registers reliably, Enter confirms, Escape cancels, and clicking away commits the new name
- Fixed a keypose dot on the motion path occasionally missing from the inspector preview when the current frame sat between or past the keyposes
- Fixed a potential rendering failure with dashed and draw-on strokes
